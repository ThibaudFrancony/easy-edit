# Easy Edit

Petit logiciel de montage vidéo pour macOS (Electron, React, FFmpeg), pensé pour monter les clips de ReplayClip : rapide, animé, sobre.

```bash
npm install
npm run dev
```

`npm run install-app` construit l'app et l'installe dans /Applications. Détails du projet et conventions : [AGENTS.md](AGENTS.md). Feuille de route : [TODO.md](TODO.md).
